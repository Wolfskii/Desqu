## Default Permission

Shell settings and app info for the UI

#### This default permission set includes the following:

- `allow-get-shell-settings`
- `allow-set-shell-settings`
- `allow-app-info`
- `allow-update-status`
- `allow-check-update`
- `allow-install-update`
- `allow-open-releases-page`
