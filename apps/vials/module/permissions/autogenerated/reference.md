## Default Permission

Everything the Vials UI needs

#### This default permission set includes the following:

- `allow-get-config`
- `allow-set-config`
- `allow-list-items`
- `allow-item-icon`
- `allow-assign-item`
- `allow-open-item`
- `allow-create-vial-from-menu`
- `allow-dismiss-menu`
- `allow-menu-ready`
- `allow-begin-rename`
- `allow-end-rename`
- `allow-drop-items`
- `allow-drag-item-out`
- `allow-get-monitors`
- `allow-desktop-status`
- `allow-module-start`
- `allow-module-stop`
- `allow-module-status`
