## Default Permission

Everything the Workspaces UI needs

#### This default permission set includes the following:

- `allow-get-config`
- `allow-set-config`
- `allow-list-desktops`
- `allow-list-items`
- `allow-item-icon`
- `allow-assign-item`
- `allow-desktop-status`
- `allow-module-start`
- `allow-module-stop`
- `allow-module-status`
